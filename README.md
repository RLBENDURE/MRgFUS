# MRgFUS Surgical Planning Tool
**University of Florida | BME 6018 Clinical Correlations | Spring 2026**

---

## Overview
This project develops a pre-operative surgical planning tool for noninvasive MRgFUS
(Magnetic Resonance guided Focused Ultrasound) thalamotomy in patients with refractory
tremor. The tool enhances patient inclusion criteria assessment through nuanced SDR
Kurtosis analysis and utilizes SHAP modeling as a communication aid for neurosurgeons
in planning their surgical pipeline — reducing potential error, time, and cost.

---

## Background
Few studies critically reassess MRgFUS patient inclusion criteria beyond standard skull
density ratio measurements. SDR Kurtosis remains an underutilized metric despite its
prognostic value. Only one prior study has applied SHAP modeling to MRgFUS thalamotomy,
and only for post-operative outcomes
[(DOI: 10.3389/fradi.2025.1683274)](https://doi.org/10.3389/fradi.2025.1683274).
This work addresses the pre-operative gap.
